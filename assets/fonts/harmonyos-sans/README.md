Source: [`@1adybug/harmonyos-sans@0.1.1`](https://www.npmjs.com/package/@1adybug/harmonyos-sans/v/0.1.1),
based on HarmonyOS Sans version 2.040 from the
[official Huawei font resources](https://developer.huawei.com/consumer/cn/design/resource/).

All 150 WOFF2 files are included unchanged. The package's `wght.css` only has
its license filename reference updated to `LICENSE.txt`. The
variable font supports weights 40–900, including the website's 400, 500, 600,
and 700 weights. Unicode ranges let browsers load only the character ranges
needed on each page. The Chinese glyphs come from HarmonyOS Sans SC, including
traditional characters; Latin glyphs come from HarmonyOS Sans.

All four HTML pages load `wght.css` before the shared `styles.css`. These assets
are served locally, so visitors do not need an installed font or a third-party
font CDN. The original copyright notice and license text are retained in
`LICENSE.txt`; trailing NUL padding from the vendor license file is omitted.
